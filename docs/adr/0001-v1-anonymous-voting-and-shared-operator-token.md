# v1은 인증 없는 익명 투표와 Operator 공유 토큰을 쓴다

이 앱은 동아리·학생회의 실제 선거와 의사결정에 쓰이지만, v1에서는 Voter 로그인과 중복 Vote 방지를 구현하지 않는다. Vote는 완전 익명이며, 같은 사람이 여러 번 Vote하는 것을 막을 방법이 없다. Operator도 개별 계정 대신 모든 Operator가 공유하는 단일 비밀 토큰으로 구분 없이 인증한다. "질문을 올리면 사람들이 선택지를 고르고 결과를 본다"는 원래 요청 범위를 단순하게 지키려는 의도적 선택이며, 신뢰성보다 단순함을 우선한 트레이드오프다.

## Consequences

- Voter가 자격 있는 Member인지 v1은 확인하지 않는다. Poll 링크를 가진 사람은 누구나 Vote할 수 있다.
- Result는 참고용이다. 결과의 정당성이 다퉈질 수 있는 선거라면 v1만으로는 부족하다.
- 어느 Operator가 어떤 Poll을 만들고 마감했는지 구분할 수 없다.
- Voter 신원을 데이터 모델에 붙이는 작업(로그인, 중복 방지)과 Operator별 개별 계정은 이후 버전에서 별도로 추가한다. 그때 이 ADR을 대체하는 새 ADR을 쓴다.
